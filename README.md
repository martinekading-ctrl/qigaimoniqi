# 《重生80年代：从乞丐到富豪》（暂定名）

一款以中国广东县城为背景的 2D 斜俯视像素风生活模拟、经营养成与人生逆袭游戏。

**当前阶段：M0——规划与需求确认。游戏开发尚未开始。**

## 项目规划

完整设计与阶段边界见 [V0.1 项目总体规划](docs/PROJECT_PLAN.md)，其中区分了完整游戏长期愿景、当前阶段 M0、首个可玩版本 P0 和最小可玩经营版本 P1，并列明已确认、暂定及待确认事项。

P0 五幕详细资料见 [开发规格](docs/p0/P0_SPEC.md)、[审查与决策记录](docs/p0/REVIEW_AND_DECISIONS.md)、[验收清单](docs/p0/ACCEPTANCE.md)和[概念参考图说明](docs/p0/references/README.md)。这些文档属于 M0 开发准备，技术与最终参数仍待确认，不代表已获游戏开发授权。

当前仅归档规划；游戏引擎、目标平台、地图规格及具体数值等仍待确认。后续工作须经项目负责人确认，不自动进入游戏开发。
