# 《重生80年代：从乞丐到富豪》（暂定名）

一款以中国广东县城为背景的 2D 斜俯视像素风生活模拟、经营养成与人生逆袭游戏。

**当前阶段：M5——继续完善P0，当前交付0.5.1体验修正版，待PR审核和Windows人工验收。P0最终人工/视觉/文案验收尚未完成，不进入M6/P1。**

工程位于 `Unity/`，锁定 **Unity 6.3 LTS 6000.3.25f1**、C#与Windows PC，沿用 `Assets/Scenes/M1Greybox.unity`。[0.5.1打开、操作和Windows试玩说明](docs/p0-usability/README.md) · [0.5.1实际验证](docs/p0-usability/VALIDATION.md) · [P0逐项覆盖与待验](docs/m5/ACCEPTANCE_MATRIX.md) · [M5 0.5.0历史交付](docs/m5/README.md)。
