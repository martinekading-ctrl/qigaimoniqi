# 《重生80年代：从乞丐到富豪》（暂定名）

一款以中国广东县城为背景的 2D 斜俯视像素风生活模拟、经营养成与人生逆袭游戏。

**当前阶段：M3——陈伯废品收购与现金结算，待PR审核和Windows实机验收；不进入M4。M2审核完成，PR #4已合并。**

工程位于 `Unity/`，锁定 **Unity 6.3 LTS 6000.3.25f1**、C#与Windows PC，沿用 `Assets/Scenes/M1Greybox.unity`。[M3打开、操作和Windows试玩说明](docs/m3/README.md) · [M3实际验证与限制](docs/m3/VALIDATION.md) · [M2历史交付](docs/m2/README.md)。
