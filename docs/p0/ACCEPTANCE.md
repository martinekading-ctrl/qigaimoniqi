## 1. 验收原则与阶段门槛

五幕是体验分组，不是按序解锁任务。验收既覆盖正常求生闭环，也覆盖无钱、超重、改变顺序和保存读取。测试参数可以调节，但改动必须同步预期值，不能因通过测试而认定为历史事实。

| 阶段 | 交付目标 | 阶段验收 |
| --- | --- | --- |
| M0 | 规格、决定、测试与参考一致 | 文档自检通过；负责人另行批准技术方案与开发范围后才进入编码 |
| M1 | 连续街区、角色、相机与交互 | A经B/D可到C/E/F/G；无剧情门和永久堵路；镜头与早餐露出可验证 |
| M2 | 有限拾取、背包、家书保护、丢弃/重拾 | 数量、重量、来源点和地面状态一致；不重复领取 |
| M3 | 陈伯称重交易 | 按公斤测试价、精确到分结算；不能空卖、负库存或重复卖 |
| M4 | 餐食/帮工、开局内容、基础休息及存档 | P0从头到尾可玩；可免费休息；基础存读档能恢复已实现关键状态 |
| M5 | 跨日刷新、回归与完整P0验收 | 丢弃物跨日清理、有限资源再生、失败恢复、自由顺序与全部存档回归通过 |

M4的基础休息与存档不可延期为M5首次交付。M5对它们的跨日结果做完整实现与回归；P0通过前不得进入P1，之后也需要单独授权。

## 3. 场景、点位与自由顺序

| 用例 | 操作/前置条件 | 预期结果 |
| --- | --- | --- |
| M-01 | 新开局，不阅读家书或报纸，直接离开A | 很快获得控制；A-04始终可走，能到B/D及C/E/F/G；不被强制传送 |
| M-02 | 走过主路、C摊位与G秤前，观察路人/自行车 | 地面可读、可绕行；G-04可站立转身；没有NPC/装饰永久堵路 |
| M-03 | 核对20个点位及类型 | 与规格4.1唯一清单一致；D-03是瓶2、F-03是金属；不补C/G缺号；D-04不产物、G-01不发奖励 |
| M-04 | 从A/B向D、C移动 | B视角只见远处早餐蒸汽/棚布局部，走近C才完整展示；不照概念图固定坐标 |
| O-01 | 不读信；先空手找陈伯；先无钱找林婶；先发现E | 各路线独立可继续，无需前一句对白或前一幕完成；旧壶仅记录线索 |
| O-02 | 打开并关闭对话/菜单，取消交互或交易 | 可以正常离开；取消不改变资产，不产生永久卡死 |

## 4. 拾荒、重量与地面状态

| 用例 | 操作/前置条件 | 预期结果 |
| --- | --- | --- |
| I-01 | 依次取B-02、D-01、D-02、D-03，再反复访问 | 两份纸和两只瓶，共3kg；同日不重复生成，场景与背包一致 |
| I-02 | 已有3kg基础四物，再尝试拾取F-03 | 6kg超过5kg，拾取失败；金属原位保留，库存/重量不变 |
| I-03 | 丢弃一件普通废品，当天离开返回并重拾 | 库存扣除、地面生成一次；重拾受承重限制，成功后移除地面记录；来源点不重置 |
| I-04 | 拾取/搜索后丢弃，反复重拾或操作原来源点 | 原生点、地面和背包不能同时保留副本；当天来源产出不增加 |
| I-05 | 查看/重复阅读家书，尝试出售、丢弃或消耗 | 开局始终拥有；重量贡献0；所有破坏性操作不可用；阅读不限制其他玩法 |
| I-06 | 多次搜索F-01/F-02；尝试拿店内货物或D-04自行车 | 搜索当天有限；非授权私产无免费拾取功能；只有明确弃置/授权对象可获取 |

## 5. 交易、餐食与旧壶

| 用例 | 操作/前置条件 | 预期结果 |
| --- | --- | --- |
| E-01 | 向G-03卖出基础两份纸、两只瓶 | 称重3kg，收入精确44分；背包扣除对应数量；不把0.10元/瓶误当每kg价 |
| E-02 | 持有3kg金属一件并出售 | 按16分/kg得到48分；数量、重量和现金一致 |
| E-03 | 空背包/数量不足时成交；取消；反复交谈或返回再卖同一批废品 | 无效成交不成立；取消不改变资产；已售物品无法重卖，无负库存或负现金 |
| L-01 | 有44分时买26分基础餐；另测余额不足购买 | 正常路径剩18分并有进食反馈；买不起不扣钱，不把玩家锁在对话中 |
| L-02 | 无钱时完成C-04帮工并领取，再对话/返回/跨日 | 只获得一次基础餐食，现金不增加；领取后不再发餐；不形成重复劳动刷奖励循环 |
| L-03 | 帮工领取后保存读取，另测领取前保存读取 | 已领状态准确恢复，不能再领；未领取状态不被误记为已领；同一有效游戏状态只兑付一次 |
| Q-01 | 先后/重复观察E-01并与E-02交谈 | 可查看线索，不给必赚答案；不能拿走、买入、议价、出售旧壶；不开启P1市场系统 |

## 6. 休息、跨日恢复与保存回归

| 用例 | 操作/前置条件 | 预期结果 |
| --- | --- | --- |
| R-01 | 现金为0，帮工已领取，当日可用资源耗尽，回A-01 | 免费休息进入次日，无住宿费或自有住宅；随后可通过有限刷新资源继续谋生 |
| R-02 | 当天丢弃物尚在地面时休息跨日 | 上日丢弃物清理；背包未丢弃物保留；帮工领取不重置；正常来源按有限规则刷新 |
| R-03 | 同日反复搜索、离开返回、读档，再推进次日 | 同日不能额外刷物；次日有明确有限产出；具体周期/数量在后续验证后同步规格 |
| S-01 | 在拾取、卖货、买餐、帮工和发现线索后分别存读档 | 位置/朝向、日期时间、现金、库存、点位、阅读、餐食领取、线索与提示一致，不复制奖励 |
| S-02 | 丢弃后存读档；重拾后存读档；跨日清理后再存读档 | 分别只存在正确的地面或背包副本；清理后的旧丢弃物不复现；原来源领取状态正确 |
| S-03 | 在任一自由顺序路径保存后继续游玩 | 仍可自由探索/交易/休息；不因读取剧情标志产生新隐形门或重新发家书 |
