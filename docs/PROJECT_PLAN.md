## 1. 游戏概述与设计支柱

**工作名称**：《重生80年代：从乞丐到富豪》（暂定）。

**类型**：2D 斜俯视/等距感像素风、自由移动探索、生活经营、剧情与年代变迁；不是 3D，不是纯文本选项游戏，也不是单纯挂机放置游戏。

**背景**：1985—2000 年，一座虚构的中国广东县城。场景具有潮湿小巷、老旧民居、骑楼或沿街店面、集市、自行车、旧式招牌等生活气息，具体细节需按年代核查。建筑与居民状态随阶段变化，而非每年重建全地图。

**核心承诺**：从身无分文开始，通过实地寻找货源、搬运、议价和经营逐步生活自立；与人物建立有后果的联系；见证十五年时代变化。财富不是唯一结局。

**设计支柱**：
- 时间推动世界，行动推动命运。
- 前期亲自劳动，中期经营判断，后期有限授权并兼顾人生。
- 通过有限、复用的系统支撑多样体验；避免独立功能堆叠。

## 2. 主角、故事与 NPC

### 2.1 主角与穿越设定（已确认）

- 现代主角约 28 岁，曾创业失败；主要原因是误判市场需求与盲目扩张。具体行业尚待确定。
- 穿越为意外、非自愿事件；现代身体的下落**未定**，不得擅自写成死亡。
- **禁止恢复“现代主角因自杀而换得奖励性新生”的旧提案；该设定已明确取消。**
- 穿入 1985 年已去世的约 21 岁贫困青年身体，暂名陈生/阿生；不存在双灵魂争夺身体。
- 原主从广东乡村外出谋生，被招聘骗局骗走积蓄，后生活困顿、流落街头，在小巷死去。家里只有一位年迈母亲。
- 主角保留现代完整记忆，原主碎片记忆通过信件、地标、旧识等逐渐触发。
- 不将超自然穿越解释做成抢占主线的科幻谜题。

### 2.2 核心人物（名称暂定）

| 人物 | 叙事/玩法功能 | 长期关系方向 |
| --- | --- | --- |
| 陈伯 | 废品收购站、首笔收入、交易信誉引导 | 商业导师或熟人关系 |
| 林婶 | 早餐摊、生活支持、县城人情 | 早期温暖与邻里联系 |
| 阿强 | 同辈小贩、有限动态竞争 | 朋友、竞争者、合作伙伴或分道扬镳 |
| 原主母亲 | 身份认同、家庭责任 | 贯穿人生的重要情感线 |

NPC分层：路人（氛围）、功能NPC（交易/任务）、少量核心NPC（按时代发展及条件分支）。**不模拟全体居民自主生活。**

## 3. 四个篇章与人生方向（完整游戏愿景）

| 篇章 | 年份 | 主题 | 代表经营内容 |
| --- | --- | --- | --- |
| 第一章 | 1985—1987 | 活下去 | 拾荒、旧货收购、初次摆摊 |
| 第二章 | 1988—1991 | 站稳脚跟 | 固定商铺、供货关系、基础用工 |
| 第三章 | 1992—1995 | 时代的机会 | 业务转型、合作与有限扩张 |
| 第四章 | 1996—2000 | 人生的答案 | 多店管理、家庭与人生选择 |

- 日常可通过休息推进，长年份通过玩家主动确认的章节/阶段跳跃完成；无需逐日游玩十五年。
- **没有强制财富门槛**：完成必要剧情条件即可推进，即使没有商铺、曾亏损或选择平凡生活也可进入新篇章。
- 主角可走向财富、稳定小生意、社会合作或失败再起；结局反映事业、家庭、人际与人生经历四个维度。
- 时代推进伴随重要NPC、市场和少量地标的阶段性变化；街道布局应保持连续性。

## 4. 核心操作与经济循环

### 4.1 玩家基本循环

1. 在实际街区自由移动，观察/寻找有价值的物品和消息。
2. 拾取可见废品、搜索有限的垃圾堆/场所，或向NPC收购旧货。
3. 使用有重量限制的背包及运输工具携带货物，决定保留哪些物品。
4. 废品按重量出售；旧货依据品相、需求、买家和信誉报价，可有限议价（通常 1—2 轮）。
5. 结算现金、对应库存和成本；购买食物、改善生活，或为下一笔生意留本金。
6. 通过睡觉和有限刷新进入下一经营日，重复循环并推进人物关系。

### 4.2 物品与运输

- 搜索点有有限产出和合理刷新条件；禁止无限搜索刷钱。
- 负重按重量结算；身体携带、麻袋、手推车、后期三轮货运为渐进升级。
- 手推车可切换推车状态、停靠并装卸，拥有独立货仓；**不做高成本物理推车模拟**。
- 过去提到的 10kg/20kg/60kg 仅是测试示例，**不是最终容量**。

### 4.3 经济正确性

- 现金、库存/资产、债务、经营利润分别记录；贷款不算收入，库存不算实际回款。
- 利润以已售货物的对应成本及适用费用计算；现金以实际收付变化为准。
- 不允许重复出售、负库存、货物跨店复制和零风险无限套利。
- 保留拾荒、短工等低门槛复原方式，防止破产后无法继续游玩。
- 商品物价、食物、工资、租金、贷款条件必须按对应年代研究与平衡，当前未冻结具体数值。

## 5. 商业、信誉、市场与现代知识（长期方向）

### 5.1 经营难度（已确认：B 中度经营）

玩家会因价格判断、库存积压、固定费用、债务或扩张而亏损，甚至关闭店铺。但不强制游戏结束，需保留合理恢复途径。风险应随经营规模增长，早期以生存和交易学习为主。

### 5.2 借贷与商业信誉（已确认）

- 熟人信任达到条件后可小额借款；稳定经营后逐步出现赊货和符合当年制度的融资选择。
- 区分私人信任与商业信誉；有限传播只发生在有关系的关键商人之间。
- 经营亏损不自动等于不诚信；故意违约、长期不履行约定才影响相关口碑。
- 债务包含金额、期限与偿还状态；到期有提醒、协商和后果，不允许简单跨年抹除。

### 5.3 有限动态商业竞争（已确认：B）

- 少量重要商人根据有限市场信息、库存与角色阶段适度调价、改变货品或减少进货。
- NPC不得无限降价、无限进货或即时读取玩家未公开信息。
- 阿强是早期竞争系统的优先测试对象；**不做全县城经济AI**。

### 5.4 市场情报（已确认：C）

- 已知报价、玩家交易记录和确认过的行情可查；注明记录时间，旧消息可能失效。
- 特殊商机通过观察、走访、商人介绍和剧情获得，消息不一定保证准确。
- 现代主角拥有经营管理经验和重要时代趋势预判，**不掌握每笔必赚交易的未来答案**。

## 6. 雇员、授权与多店经营（长期方向，不属于P0/P1）

- 多行业仅限相互关联的旧货、电器维修/销售、日用零售等方向；不扩张至无数互不相关的行业。
- **“最多3个经营据点”是暂定建议，未获正式确认**；需在单店经营验证后冻结。
- 员工来自普通招聘与少量特殊NPC关系；合适的普通员工可晋升店长。
- 员工使用少量经营属性（如熟练度、可靠程度、工作满意度），不模拟复杂生活需求。
- 店长在授权预算、单笔进货上限、定价边界内自主处理销售、常规补货等日常工作；可判断失误，但不得擅自借贷、转型、开关店或越权动用资产。
- 店铺承担正常商业亏损，不因一次误判直接扣员工工资或认定员工恶意。
- 日常经营定期出账；持续严重亏损、资金危机和重大人员变化触发重要待办。
- 玩家可查看已经获得的报表，**不凭空获知远方店铺的实时数据**；通知根据年代与场所，通过口信、当面、电话等合理方式送达，兼顾操作便利。
- 跨年只在可能不可逆失去关键资产/店铺或发生必须由玩家选择的重大事件时暂停；常规风险由授权策略结算。

## 7. 美术、历史与内容范围约束

- 首版以小型连通街区和少量可复用物件为主，建立统一像素尺度、角色比例、场景透视与可交互标识。
- 1985年的服饰、交通、广告、食品、货币和商业活动应做历史核查；不使用现代物品填充街景。
- 广东气候按地域设置，不随意做北方雪景；首版不需要复杂全季节系统。
- 县城的年代变化优先修改街区状态、建筑外观、招牌、商铺和NPC，不重新制作每年的完整地图。
- 任何新加入的美术/剧情素材都应复用核心交互系统，避免为一个事件开发独立小游戏。

## 9. P0：1985年首个可玩切片

**目标**：玩家在一个小区域中完成从小巷醒来到第一笔收入、买到食物的闭环。

### 9.1 必需内容

| 领域 | 范围 |
| --- | --- |
| 场景 | 破旧小巷、一段相连街道、废品收购站、早餐摊 |
| 角色控制 | 2D斜俯视移动、碰撞、靠近互动与简短对话 |
| 拾荒 | 少量可见废品与指定搜索点；有限产出 |
| 背包 | 物品数量、单件重量、总负重、拾取与放下 |
| 废品交易 | 与陈伯称重出售，正确结算现金和库存 |
| 生存消费 | 向林婶购买食物，获得基础生活反馈 |
| 时间 | 简单的一天循环、休息和有限刷新 |
| 剧情 | 非冗长醒来剧情、旧信与1985年环境证据 |
| 存档 | 位置、现金、背包、日期、基础事件状态正确恢复 |

### 9.2 开局前30分钟草案（仅体验目标，不强制计时）

| 体验段 | 玩家经历 | 验证重点 |
| --- | --- | --- |
| 0—3分钟 | 小巷醒来、控制角色、信件与年代线索 | 尽快可操作，少强制剧情 |
| 3—8分钟 | 走入街道，发现并捡起废品 | 移动、探索、背包和负重 |
| 8—13分钟 | 找到陈伯，称重卖出废品 | 交易闭环和现金反馈 |
| 13—18分钟 | 在林婶摊位用收入购买食物 | 生活反馈和NPC关系 |
| 18—30分钟 | 看到可能转卖的旧货、获得线索 | 引出后续经营而非一次做完 |

### 9.3 P0验收

- [ ] 无需长时间被动观看，玩家能快速控制角色并走出小巷。
- [ ] 可独立完成“拾荒→整理负重→出售→获取现金→购买食物”。
- [ ] 交易前后库存、重量、现金始终一致，不可重复领取或重复出售。
- [ ] 玩家即使未在首次尝试中赚到足够的钱，也有合理的继续谋生途径。
- [ ] 场景物品、台词、NPC和氛围基本符合1985年广东县城。
- [ ] 保存读取后，重要物品、现金、日期、位置和剧情进度不丢失。
- [ ] 无阻断主流程的严重错误。

**P0验收通过之前不进入P1。**

## 10. P1：首版最小可玩经营体验

**目标**：让玩家在多个游戏日里重复探索、判断、交易，体验至少一笔可能盈利也可能亏损的旧货买卖。

**在P0稳定后增加**：
- 约3—4类可回收废品、约3—5种旧货（均为建议量级）。
- 旧货品质、买入成本、不同买家出价、1—2轮有限议价。
- 简单行情笔记：已知报价、时间、消息来源。
- 一条通过与NPC交流发现的特殊商机。
- 阿强作为简单、可解释的竞争商人，影响少量商品。
- 多个游戏日的市场与物品刷新规则，防止刷钱。
- 至少一种早期运输升级（例如麻袋或手推车），以实际平衡结果选择。
- 一条小规模NPC关系分支与可恢复的经营失败情境。

### P1验收

- [ ] 核心循环“找货源→估价→购入或收集→运输→出售→结算”可重复进行。
- [ ] 至少一类旧货具备真实盈亏和可解释的市场差异。
- [ ] 资金不足时，仍可以从低风险劳动重新起步。
- [ ] 商品不会凭空复制，商人买卖价差与收购量不产生无限套利。
- [ ] 市场信息记录能帮助决策，而不是自动提示必赚答案。
- [ ] 基础NPC竞争可观察、可理解，并非即时作弊。
- [ ] 保存读取能恢复经济、时间与NPC关键事件状态。
- [ ] 测试玩家愿意完成多天交易，而不是依靠强制任务驱动。

## 11. 明确不在P0/P1中的内容

- 全部1985—2000年四章可玩剧情与长时间跳跃。
- 固定商铺、多店、店长、复杂员工成长与自动化管理。
- 正规融资和完整负债系统、合伙股权与公司治理。
- 高度动态全县经济、每名NPC的自主资产及生活系统。
- 完整维修小游戏、大量商品工艺或几十种行业。
- 婚恋/养育/完整家庭模拟及全部结局。
- 整座县城、十五年全部场景变化、全季节复杂天气。
- 3D、美术资产海量制作、复杂物理、联网等未提出需求。

## 13. Codex的工作规则
