# 《重生80年代：从乞丐到富豪》（暂定名）

一款以中国广东县城为背景的 2D 斜俯视像素风生活模拟、经营养成与人生逆袭游戏。

**当前阶段：M1——Unity灰盒原型，待验收；尚未进入M2。**

工程位于 `Unity/`，锁定 **Unity 6.3 LTS 6000.3.25f1**、C#与Windows PC。[打开、运行和Windows试玩说明](docs/m1/README.md) · [实际验证与限制](docs/m1/VALIDATION.md)。

## 项目规划

完整设计与阶段边界见 [V0.1 项目总体规划](docs/PROJECT_PLAN.md)，其中区分了完整游戏长期愿景、当前阶段 M0、首个可玩版本 P0 和最小可玩经营版本 P1，并列明已确认、暂定及待确认事项。

P0 五幕详细资料见 [开发规格](docs/p0/P0_SPEC.md)、[审查与决策记录](docs/p0/REVIEW_AND_DECISIONS.md)、[验收清单](docs/p0/ACCEPTANCE.md)和[概念参考图说明](docs/p0/references/README.md)。完整规划不代表实现全部P0的授权；当前仅M1子集获批，最终地图与像素规格仍待确认。

当前仅实现M1七区灰盒、角色移动、镜头与2D碰撞。地图与像素尺度仍为原型参数；拾取、背包、交易、食物、帮工、时间和存档均未实现。M1验收通过并获批准后才进入M2。
